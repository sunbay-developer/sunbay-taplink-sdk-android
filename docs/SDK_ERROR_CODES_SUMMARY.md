# SDK 错误码统计

本文档统计了 Taplink SDK 中使用的所有错误码，包括通信层错误码和 SDK 层验证错误。

## 1. 通信层错误码 (InnerErrorCode)

这些错误码定义在 `lib_taplink_communication` 模块中，用于底层通信和连接管理。

### 1.1 成功响应
- **0**: 成功响应

### 1.2 安全限制错误 (S 系列)
- **S01** - **S09**: 安全限制相关错误

### 1.3 客户端错误 (C 系列)
- **C01** - **C67**: 客户端相关错误
  - **C20**: 连接错误
  - **C22**: 连接错误
  - **C25**: 通用连接错误
  - **C33**: 连接错误
  - **C35**: 连接错误
  - **C36**: 自动连接断开错误
  - **C37**: 连接启动失败
  - **C41**: 协议解析错误
  - **C43**: 参数验证错误（金额相关）
  - **C44**: 初始化失败
  - **C45**: 连接超时
  - **C48**: USB 协议错误
  - **C49**: USB 权限请求失败
  - **C50**: USB 设备连接失败
  - **C51**: USB 权限请求异常
  - **C52**: USB 设备未找到
  - **C53**: USB 设备无权限
  - **C54**: USB 设备打开失败
  - **C55**: AOA 协议序列失败
  - **C56**: AOA 连接断开
  - **C57**: 连接状态错误
  - **C58**: 协议类型不匹配
  - **C61**: 未连接状态发送数据
  - **C62**: 数据发送失败
  - **C63**: 数据发送异常

### 1.4 商户配置错误 (M 系列)
- **M01** - **M04**: 商户配置相关错误

### 1.5 支付渠道错误 (P 系列)
- **P01**: 支付渠道错误

### 1.6 系统错误 (E 系列)
- **E01** - **E03**: 系统错误
- **E04**: 异常错误

### 1.7 风控拦截 (R 系列)
- **R01**: 风控拦截错误

### 1.8 其他错误码
- **996**: 超时错误

## 2. SDK 层验证错误 (ValidationError)

这些错误用于 SDK 层的请求参数验证。

### 2.1 基础字段验证错误
- **MissingTransactionRequestId**: 缺少交易请求ID
- **MissingReferenceOrderId**: 缺少参考订单号
- **MissingAmount**: 缺少金额信息
- **MissingDescription**: 缺少描述信息

### 2.2 金额验证错误
- **InvalidAmount**: 金额必须为正数
- **InvalidTipAmount**: 小费金额必须为非负数

### 2.3 原始交易引用验证错误
- **MissingOriginalTransaction**: 缺少原始交易引用

### 2.4 退款模式验证错误
- **InvalidRefundMode**: 退款模式无效

### 2.5 自定义验证错误
- **CustomError**: 自定义验证错误

## 3. SDK 错误类型

### 3.1 ConnectionError
连接错误类，包含以下字段：
- `code`: 错误码
- `message`: 错误描述
- `deviceId`: 设备ID（可选）
- `suggestion`: 处理建议（可选）

### 3.2 PaymentError
支付错误类，包含以下字段：
- `code`: 错误码
- `message`: 错误描述
- `orderNo`: 订单号（可选）
- `transactionId`: 交易ID（可选）
- `suggestion`: 处理建议（可选）

### 3.3 TaplinkException
SDK 异常类，继承自 Exception。

## 4. 错误消息资源

SDK 中定义的错误消息字符串资源：

### 4.1 金额验证错误消息
- `error_invalid_amount_order`: 订单金额必须为整数，不能为小数
- `error_invalid_amount_tip`: 小费金额必须为整数，不能为小数
- `error_invalid_amount_tax`: 税费金额必须为整数，不能为小数
- `error_invalid_amount_surcharge`: 附加费金额必须为整数，不能为小数
- `error_invalid_amount_cashback`: 返现金额必须为整数，不能为小数
- `error_invalid_amount_service_fee`: 服务费必须为整数，不能为小数

## 5. 错误码使用场景

### 5.1 连接管理中使用的错误码
- C20, C22, C25, C33, C35, C36: 通用连接错误
- C41: 协议解析错误
- C44, C45: 初始化和超时错误
- C48-C56: USB AOA 相关错误
- C57, C58: 连接状态和协议类型错误
- C61-C63: 数据传输错误

### 5.2 支付管理中使用的错误码
- C36: 自动连接断开
- C43: 参数验证错误（主要用于金额验证）

### 5.3 验证错误的使用
- 在各种交易请求类的 `validate()` 方法中使用
- 在构建器的 `build()` 方法中抛出 `TransactionRequestValidationException`

## 7. 错误处理建议

1. **连接错误**: 检查设备连接状态，重试连接
2. **参数验证错误**: 检查请求参数格式和值
3. **系统错误**: 联系技术支持
4. **安全限制错误**: 检查权限和安全配置
5. **超时错误**: 增加超时时间或检查网络状况

## 8. 多语言支持

错误码描述支持多语言本地化，通过 `ErrorStringHelper.getDescription(code)` 获取本地化描述。
