# Amount字段文档更新总结

## 更新内容

根据要求，在Sunbay Taplink SDK for Android集成指南中添加了关于amount字段的详细说明，明确指出所有金额必须以最小货币单位（smallest currency unit）表示。

## 具体更新

### 1. 核心概念新增 - 金额单位规范（2.6节）

在核心概念部分新增了完整的金额单位规范说明：

- **基本概念**：解释了基本货币单位与最小货币单位的区别
- **货币对照表**：提供了USD、EUR、JPY、CNY、GBP等主要货币的换算关系
- **使用原因**：说明为什么要使用最小货币单位（避免浮点数精度问题、符合国际标准等）
- **实际应用**：提供了正确和错误的代码示例
- **常见货币换算表**：详细的金额换算对照表
- **ISO-4217参考**：提供了国际标准的链接

### 2. AmountInfo类说明增强

在`AmountInfo`类的文档中添加了：

- **重要说明**：明确所有金额字段必须以最小货币单位表示
- **货币示例**：
  - USD（美元）：以分为单位，例如 $1.00 = 100
  - EUR（欧元）：以分为单位，例如 €1.00 = 100  
  - JPY（日元）：以日元为单位，例如 ¥100 = 100
  - CNY（人民币）：以分为单位，例如 ¥1.00 = 100
- **ISO-4217参考**：提供了ISO-4217标准的链接
- **代码示例**：展示了正确和错误的用法

### 3. TransactionAmount类说明

为`TransactionAmount`类添加了说明，明确所有返回的金额字段都以最小货币单位表示。

### 4. BatchCloseInfo类说明

为`BatchCloseInfo`类添加了说明，明确所有金额字段都以最小货币单位返回。

### 5. 示例代码更新

更新了文档中所有的金额示例代码，将原来使用主货币单位的示例（如100.00）改为使用最小货币单位（如BigDecimal("10000")）：

- 销售交易示例：$100.00 → 10000分
- 退款交易示例：$100.00 → 10000分，$50.00 → 5000分
- 预授权示例：$500.00 → 50000分，$450.00 → 45000分
- 小费调整示例：$15.00 → 1500分

## 更新位置

主要更新了以下文档：
- `docs/Sunbay Taplink SDK for Android - 集成指南.md`

## 关键改进

1. **系统性说明**：在核心概念部分提供了完整的金额单位规范
2. **明确性**：清楚说明了amount字段的格式要求
3. **标准化**：引用了ISO-4217国际标准
4. **实用性**：提供了多种货币的具体示例和换算表
5. **一致性**：确保所有代码示例都使用正确的格式
